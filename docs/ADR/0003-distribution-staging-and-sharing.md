# ADR 0003: Distribution staging and address-free sharing

Status: implemented locally; staging acceptance pending. Date: 2026-10-07 UTC.

The Free scoring engine is frozen at v0.1.0. Distribution changes start with SiteBuddy identity and a privacy-minimized share loop. A result summary encodes only three scores, their validated total, model version, UTC day and public/synthetic mode in a URL fragment. No result database, address, coordinates, user identifier or record list is created. Fragments are not part of HTTP requests; JavaScript integrations must never forward them. Recipients see an editable, sender-provided summary, not independently verified evidence. The existing full replay download remains separate and is explicitly disclosed as containing location and normalized records.

An initial native-share experiment left the UI awaiting an unobserved system-sheet outcome during browser QA. The simpler selected design copies a summary and link. Clipboard success is reported only when its promise resolves; unsupported, denied or stalled clipboard falls back to selectable text after at most two seconds. Native share is deliberately omitted. Unknown dimensions stay unknown, and malformed or inconsistent summaries cannot populate the result UI. A static social preview will describe the product rather than an address-specific result. Tradeoff: omitting the address reduces context and virality but avoids accidentally publishing candidate-location details. Visitors can analyze their own address immediately.

Netlify is the selected host. The first new-feature environment is a separate, non-indexed staging project/branch; it is not the approved production product. No production branch promotion may precede staging acceptance. Automatic approval rejected an earlier attempt to create a production ref before staging; the ref was not changed and no workaround promotion is permitted. Preview commits are explicitly work in progress, required for hosted QA, not PASS checkpoints. After preview evidence passes, record the approved checkpoint and promote only that tested source through the production gate. Keep the original public v0.1.0 prototype unchanged.

Preview artifacts default to noindex in HTML and response headers and disallow crawler access. Production indexability additionally requires an explicit reviewed release environment flag. No paid upgrade, domain or additional account is introduced.
