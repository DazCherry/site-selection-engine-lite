# Publication checklist

- Every capability classified before implementation; uncertain functionality remains excluded.
- Fresh public history; no confidential documents or private repository imports.
- Synthetic fixtures generated independently; no customer-derived records or coefficients.
- All tracked files and history inspected; automated secret, path and restricted-term checks pass.
- No API keys, private identifiers, internal endpoints or personal filesystem paths.
- Public model card matches actual formulas, unknown handling, category groups and limitations.
- Data provenance, display attribution and license links present; source terms reviewed.
- Unit, integration, independent calculation, adversarial, regression and browser checks recorded truthfully.
- Clean checkout reproduces without undeclared dependencies.
- Public GitHub source and deployable static assets agree; release tag points to reviewed commit.
- Final report distinguishes observed success, untested optional interfaces, provider outages and deferred capabilities.
